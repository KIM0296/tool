# 유튜브 영상 읽기

이 저장소의 `ytread` 도구로 자막을 가져온 뒤, 요약·정리는 Claude가 직접 한다 (API 키 불필요).

## 1. 자막 가져오기

```bash
python -m ytread "<유튜브 주소>" -f markdown
```

- 명령이 없다는 오류(`No module named ytread` 또는 `youtube_transcript_api`)가 나면 저장소 루트에서 `pip install -e .` 를 한 번 실행하고 다시 시도한다.
- 영어 영상 등 다른 언어를 우선하려면 `-l en,ko` 를 붙인다.
- 자막이 매우 길면 `-o <scratchpad 경로>/transcript.md` 로 저장한 뒤 나눠 읽는다. 절대 앞부분만 읽고 요약하지 않는다.
- **자막이 없는 영상**은 자동으로 음성 인식(Whisper)으로 받아쓴다. 영상 길이에 따라 몇 분 걸리므로, 실행 전에 사용자에게 "자막이 없어 음성을 받아쓰는 중"이라고 한 줄 알리고 Bash 타임아웃을 넉넉히(최대 600000ms) 준다. 1시간 이상 긴 영상은 `run_in_background`로 실행한다.
- 음성 인식이 부정확하면 `-m medium` (더 정확, 더 느림)으로 다시 시도할 수 있다고 제안한다. 자막이 있어도 음성으로 받아쓰려면 `--speech`.
- `--summarize` / `--ask` 옵션은 쓰지 않는다 (별도 API 키가 필요한 기능이다). 요약은 직접 한다.

## 2. 사용자에게 답하기

사용자가 특별히 요청한 형식이 없으면 다음 순서로 한국어로 정리한다.

1. **한 문단 핵심 요약**
2. **주요 내용 목차** — 각 항목에 타임스탬프 링크 (`[03:15](https://www.youtube.com/watch?v=ID&t=195s)`)
3. **기억할 포인트** — 수치, 고유명사, 추천 도구·자료, 실천 항목

질문을 받았다면 자막에서 근거를 찾아 답하고 해당 타임스탬프를 붙인다.

## 규칙

- 자막에 있는 내용만 근거로 한다. 자막에 없는 내용은 "영상에서 언급되지 않았다"고 말한다.
- 자동 생성 자막이나 음성 인식 결과(출력의 `자막: ... (자동 생성)` / `(음성 인식 ...)`)이면 고유명사·숫자가 틀릴 수 있다고 한 줄 알린다.

## 오류가 날 때

| 오류 메시지 | 의미 / 대응 |
|---|---|
| `음성 인식 기능이 설치되지 않았습니다` / `... pip install -e ".[speech]"` | 자막이 없는데 음성 인식 패키지가 없음. 저장소 루트에서 `pip install -e ".[speech]"` 실행 후 재시도. |
| `음성 인식 모델(...)을 불러오지 못했습니다` | 첫 실행 시 모델 다운로드 실패. 인터넷 연결을 확인하고 재시도. |
| `오디오를 내려받지 못했습니다` | yt-dlp 다운로드 실패. `pip install -U yt-dlp` 로 업데이트 후 재시도. |
| `RequestBlocked`, `IpBlocked` | 유튜브가 현재 네트워크(주로 클라우드 서버)를 차단함. 개인 PC에서 실행해야 한다고 안내한다. |
| `VideoUnavailable`, `AgeRestricted` | 비공개·삭제·연령 제한 영상. 읽을 수 없다고 안내한다. |
| `유튜브 영상 주소나 ID로 인식할 수 없습니다` | 링크를 다시 확인해 달라고 한다. |
